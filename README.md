# Sporty - React + Vite Parity Conversion

Project static HTML/CSS/JS/Bootstrap đã được chuyển sang React + Vite theo hướng parity 1:1 (giữ nguyên giao diện và hành vi gốc).

## Yêu cầu

- Node.js >= 16
- npm

## Cài đặt

```bash
npm install
```

## Chạy môi trường dev

```bash
npm run dev
```

## Build production

```bash
npm run build
```

## Preview build

```bash
npm run preview
```

## Tài liệu

- `docs/mapping-inventory.md`: kiểm kê HTML/CSS/JS/assets/localStorage/functions/navigation.
- `docs/proposed-structure.md`: cấu trúc React/Vite đề xuất và đã áp dụng.
- `docs/mapping-pages.md`: mapping từng HTML sang React page/route.
- `docs/qa-checklist.md`: checklist QA parity.
- `docs/screenshots/`: ảnh đối chiếu legacy vs React theo viewport.
